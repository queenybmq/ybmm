# 扫雷游戏 - 产品需求文档

## 1. 产品概述

一款极简优雅风格的网页扫雷游戏。玩家需要在不踩到地雷的情况下揭开所有非雷方块。无猜扫雷机制确保首次点击安全，插旗功能帮助标记可疑位置，当旗帜数量与数字匹配时支持自动展开。

## 2. 核心功能

### 2.1 游戏功能
| 功能 | 描述 |
|------|------|
| 无猜扫雷 | 首次点击不触发地雷，雷区在首次点击后生成 |
| 方块展开 | 点击安全方块自动展开，空白区域递归展开 |
| 数字提示 | 显示周围8个方向的地雷数量（1-8） |
| 插旗标记 | 右键/长按标记地雷位置 |
| 自动展开 | 当周围旗帜数等于数字时，自动展开未标记方块 |
| 游戏结束 | 踩到地雷显示所有地雷位置，游戏胜利条件为揭开所有安全格 |

### 2.2 难度级别
| 难度 | 网格 | 地雷数 |
|------|------|--------|
| 初级 | 9×9 | 10 |
| 中级 | 16×16 | 40 |
| 高级 | 30×16 | 99 |

## 3. 用户界面设计

### 3.1 设计风格
- **美学方向**: 日式极简禅意风格，大面积留白
- **配色方案**:
  - 背景: #F5F3EF（温暖米白）
  - 方块底色: #E8E4DC（淡灰米）
  - 方块高光: #FFFFFF（上左高光）
  - 方块阴影: #C4C0B8（下右阴影）
  - 数字颜色:
    - 1: #5C8BC9（冷静蓝）
    - 2: #6BA572（自然绿）
    - 3: #D66B6B（柔和红）
    - 4: #8B6BB9（优雅紫）
    - 5: #C96B6B（深玫瑰）
    - 6: #6BB5B5（青色）
    - 7: #4A4A4A（深灰）
    - 8: #888888（中灰）
  - 地雷: #2D2D2D
  - 旗帜: #D66B6B（柔和红）

### 3.2 立体方块设计
使用 CSS box-shadow 和渐变创造精致 3D 效果：
- **未揭开方块**: 凸起效果，深色边框模拟高度
- **已揭开方块**: 凹陷效果，模拟按下的视觉反馈
- **悬停效果**: 微妙的提亮暗示可交互

### 3.3 布局

│    │                     │      │
│    │      游戏网格        │      │
│    │                     │      │

### 3.4 交互反馈
- **点击**: 方块按下凹陷动画
- **插旗**: 旗帜出现带有轻微弹跳
- **胜利**: 网格轻微震动 + 数字闪烁
- **失败**: 地雷以脉冲动画显示

## 4. 技术实现

### 4.1 架构
- 单文件 HTML + CSS + JavaScript
- 响应式设计适配桌面和移动端
- 纯原生实现，无外部依赖

### 4.2 核心算法
1. **雷区生成**: 首次点击后，在点击位置周围3×3范围外随机放置地雷
2. **数字计算**: 统计每个方块周围8个方向的地雷数量
3. **展开算法**: BFS 扩散，空白格自动递归展开
4. **自动展开检测**: 当数字周围旗帜数等于该数字时，展开剩余未标记格子
